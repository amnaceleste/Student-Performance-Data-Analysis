# Student Performance Data Analysis

## Overview
This project uses Python to explore, clean, analyze, and visualize a sample student performance dataset.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Google Colab

## Project Tasks
- Load and explore a dataset.
- Handle missing values and remove duplicates.
- Perform basic statistical analysis.
- Create bar charts, line charts, and pie charts.

## How to Run
Open the Jupyter Notebook in Google Colab and run the cells in order.
